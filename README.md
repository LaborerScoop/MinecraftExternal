# Minecraft External

External Minecraft external for Windows. Built around one module, tuned for sandbox and running as an overlay outside the game process.

**Download:** (soon)

## Functions

- Toggle with a configurable keybind, hold or latch mode
- Independent sensitivity per profile
- Profile save/load with hot reload
- Streamproof rendering for OBS and clips
- Toggle overlay with INSERT
- Works in borderless and windowed fullscreen

### External detail
- Fine sliders instead of presets: range, speed and strength
- Per-situation profiles
- Live preview while adjusting

### Shared overlay
- Player highlighting with adjustable range
- Distance readout and colors
- Optional skeleton and health bars
- Radar widget with direction arrows and fade

## Requirements

- Windows 10 or 11
- Mojang
- Anti-cheat: none
- Borderless or windowed fullscreen

## Install

1. Download the archive
2. Extract it to a separate folder
3. Run loader.exe as administrator
4. Start Minecraft, press INSERT, load a profile
